Methodology

How FACET converts facial landmarks into geometric measurements.

1. Facial Landmark Detection

FACET uses MediaPipe Face Landmarker to identify standardized points on the face. The application operates directly on the uploaded photographs and obtains normalized landmark coordinates, which are converted to pixel coordinates before any calculation.

2. Scale Independence

Ordinary photographs do not contain enough information to determine absolute physical facial dimensions in millimeters. FACET therefore uses ratios and angles wherever possible instead of assuming a universal facial size.

A normalized ratio can be represented as:

distance(A,B) ÷ distance(C,D)

Because both distances are measured from the same individual's image, image enlargement or reduction does not change the ratio.

3. Angles

Angular measurements are calculated from vectors between detected landmarks. They are inherently independent of image scale.

4. Reference Ranges

FACET compares measurements with configured reference intervals. These ranges are provisional operational reference values and should not be interpreted as universal biological or aesthetic standards.

5. Comparison Number

The comparison value describes mathematical distance from the reference interval. A value of 0.00 represents the midpoint of the interval, while 1.00 represents a boundary. Values above 1.00 indicate increasing distance outside the interval.

This is not an attractiveness score.

6. Limitations

  • MediaPipe landmarks are approximations of anatomical points.
  • Ordinary photographs do not provide calibrated physical scale.
  • Perspective and camera position can alter apparent geometry.
  • True 90° profiles are often not detected by the model.
  • Some classical cephalometric landmarks are not directly available.
  • Some measurements therefore remain unavailable rather than being fabricated.
  • Clinical cephalometric analysis requires standardized radiographs and professional tracing.
